# Addison Eftekhari

A static personal website with parallel Teaching and Yoga sections, designed for GitHub Pages.

## Preview

Run a local server from this directory:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish

Push the contents of this directory to a GitHub repository and configure GitHub Pages to deploy from the repository's default branch and root directory.
